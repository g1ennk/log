# 2. 프로젝트 경험

"왜 그 기술을 선택했나요", "트러블슈팅 해본 적 있나요" 같은, 프로젝트에서 내가 내린 판단을 묻는 질문.

## 포맷

상황 → 선택 → 실행 → 결과

뭐가 문제였고, 어떤 대안 중에 왜 이걸 골랐고, 실제로 어떻게 구현했고, 결과가 어땠는지 순서로 말한다. 팀 성과랑 내가 한 부분은 구분해서 말하는 게 좋다.

글은 줄글이 아니라 아래처럼 라벨을 달아서 쓴다.

## 예시 — "왜 그 기술을 선택했나요?" (FlowMate 타이머 동기화에 SSE를 쓴 이유)

- 상황: 여러 탭에서 동시에 타이머를 열어놔도 항상 같은 잔여 시간을 보여줘야 했는데, 클라이언트마다 자기 타이머를 따로 돌리면 새로고침 시점에 따라 시간이 어긋났다.
- 선택: Polling과 SSE를 놓고 봤을 때, 서버가 유일한 기준이 되어야 하는 상황이라 불필요한 요청 없이 상태를 바로 밀어줄 수 있는 SSE가 맞다고 판단했다.
- 실행: 서버에서 타이머 상태를 스트리밍하고, 클라이언트는 그걸 구독해서 화면만 갱신하는 구조로 만들었다.
- 결과: 탭을 여러 개 열어도 잔여 시간이 어긋나지 않게 됐다.
