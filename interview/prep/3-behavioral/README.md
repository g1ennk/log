# 3. 행동/인성

"팀에서 갈등 있었을 때 어떻게 했나요" 같은, 기술이랑 상관없이 태도나 협업 방식을 보는 질문.

## 포맷

STAR — 상황 → 과제 → 행동 → 결과 (+ 배운 점)

기술 지식이 필요 없는 만큼 그때그때 즉흥으로 답하기보다, 미리 자기 경험 3~4개 정도를 STAR로 정리해두고 질문에 맞춰 꺼내 쓰는 게 낫다.

글은 줄글이 아니라 아래처럼 라벨을 달아서 쓴다. (템플릿 — 실제 경험으로 바꿔서 쓸 것)

## 예시 — "팀에서 의견 충돌 있었을 때 어떻게 해결했나요?"

- 상황: 아키텍처 방향을 두고 팀원과 의견이 갈렸다.
- 과제: 일정 안에 방향을 결정하고, 팀 전체가 납득할 근거를 만드는 것.
- 행동: 각자 안의 장단점을 정리해서 공유하고, 작은 프로토타입으로 빠르게 검증해본 뒤 데이터를 근거로 다시 얘기했다.
- 결과: 일정 지연 없이 방향을 좁혔고, 그 뒤로는 의견이 갈리면 먼저 프로토타입으로 확인해보는 습관이 생겼다.
