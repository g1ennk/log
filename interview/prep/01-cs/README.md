# cs

"REST가 뭔가요", "GC는 어떻게 동작하나요" 같은, 개념 자체를 설명하라는 질문.

서류를 안 봐도 나오는 질문만 여기서 다룬다. 이력서와 포트폴리오에서 출발한 질문은 개념 설명이 필요하더라도 [02-credentials](../02-credentials)에서 함께 정리한다.

## 포맷

결론 → 왜 → 원리 → 판단 기준

지식 정리가 아니라 **발화 골격**이다. 그대로 20~30초 안에 말할 수 있어야 한다.

- **결론** — 질문이 묻는 걸 그대로 되받아 1문장. 두괄식 강제 — 이것만 말해도 답이 되게.
- **왜** — 이게 왜 존재하나 / 어떤 문제를 푸나. 암기형 답변을 걸러내는 칸.
- **원리** — 동작 방식. 비교 질문이면 장단점을 나열하지 말고 "무엇을 기준으로 갈리는가" 대비축 하나로 압축.
- **판단 기준** — 언제 쓰나 / 주의점 / 한계.
