# 동일성과 동등성에 대해서 설명해주세요.

## 1. 요약

### 1.1. 결론

동일성은 두 참조가 메모리상 같은 객체를 가리키는지, 동등성은 두 객체의 값이 논리적으로 같은지를 뜻합니다.

### 1.2. 왜

이 둘을 구분하지 않으면 값이 서로 다른 객체를 다른 것으로 잘못 판단하거나, 반대로 필요한 비교 로직을 놓치는 문제가 생길 수 있어 자바는 `==` 연산자와 `equals()` 메서드로 나눠서 제공합니다.

### 1.3. 원리

`==` 연산자는 참조형에서 메모리 주소값을, 기본형에서는 값 자체를 비교하고,
`equals()`는 Object의 기본 구현상 `==`와 동일하지만, 값 기반 비교가 필요한 클래스는 이를 재정의해 필드 값을 비교하도록 만듭니다.
예를 들어 String은 이미 값 기반으로 `equals()`가 재정의되어 있어 `new String("a").equals("a")`는 참이지만, `==` 비교는 거짓입니다.

### 1.4. 장단점 및 실무

실무에서는 도메인 객체 비교 시 항상 `equals()`를 기준으로 삼습니다.
