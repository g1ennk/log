# 자바에서 클래스 정보는 어떻게 알아낼 수 있을까요?

## 1. 요약

### 1.1. 결론

자바의 Reflection API는 런타임에 클래스의 생성자, 메서드, 필드 메타데이터를 동적으로 조회하고 호출하는 기능입니다.

### 1.2. 왜

프레임워크는 사용자 클래스를 컴파일 타임에 알 수 없어, Spring DI 컨테이너처럼 임의의 클래스를 런타임에 다뤄야 할 때 이 접근 수단이 필요합니다.

### 1.3. 원리

Class, Method, Field로 JVM에 적재된 메타데이터를 읽어 타입을 몰라도 접근하며, Spring의 의존성 주입과 Hibernate의 엔티티 매핑, Jackson의 JSON 직렬화가 이 방식을 씁니다.

### 1.4. 장단점 및 실무

다만 private 접근으로 캡슐화를 위반할 수 있고 런타임 결정 때문에 일반 호출보다 느립니다. 따라서 DI, ORM 같은 프레임워크 레이어에서는 적극 활용하되, 일반 비즈니스 로직에서는 직접 사용을 피하는 것이 효율적이라고 생각합니다.
