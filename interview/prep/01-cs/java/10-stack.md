# 자료구조 스택에 대해서 설명해주세요.

## 1. 요약

### 1.1. 결론

스택은 마지막에 넣은 데이터가 가장 먼저 나오는 후입선출(LIFO) 구조의 선형 자료구조입니다.

### 1.2. 왜

대표적으로 함수 호출이나 실행 취소처럼 가장 최근 작업을 되돌려야 하는 문제를 다루기 위해선 데이터의 접근을 한쪽 끝으로 제한할 필요가 있었고, 스택은 push, pop, peek 연산을 top이라는 한쪽 끝먼 허용해 순서를 자료구조 차원에서 보장합니다.

### 1.3. 원리

배열로 구현 시 top 인덱스만 관리하면 되어 단순하고 캐시 지역성이 좋지만 초기 크기를 넘으면 재할당 비용이 들고,
연결 리스트로 구현 시 크기 제한 없이 유연하지만 포인터를 위한 메모리 오버헤드가 존재합니다.

### 1.4. 장단점 및 실무

실무에선 재귀 함수가 스택으로 동작하기 때문에 재귀 깊이가 깊어지는 로직에서는 StackOverflowError 방지를 위해 반복문과 명시적인 스택 자료구조로 바꿔 구현하기도 합니다.
