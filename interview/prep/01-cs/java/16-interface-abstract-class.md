# 인터페이스와 추상 클래스의 차이

## 1. 요약

### 1.1. 결론

추상 클래스와 인터페이스는 둘 다 하위 클래스에 구현을 강제하지만, `상태 공유 여부`와 `다중 속성 지원 여부`에서 차이점을 보입니다.

### 1.2. 원리

추상 클래스는 `abstract` 키워드로 필드와 생성자, 완성된 일반 메서드를 가질 수 있어 여러 하위 클래스가 공통 상태와 구현을 함께 재사용하는 is-a 관계를 표현합니다.
`extends`로 상속하여 자바의 단일 상속 규칙에 따라 하나만 상속할 수 있습니다.

인터페이스는 기본적으로 구현 없는 메서드의 집합으로 클래스가 어떤 행위를 할 수 있는지 계약만 정의하며, 자바 8부터는 default 메서드로 기본 구현도 제공하지만 여전히 필드는 가질 수 없습니다.
`implements`로 구현하며 어러 인터페이스를 동시에 구현하는 다중 구현이 가능합니다.

### 1.4. 장단점 및 실무

따라서 같은 계층의 클래스들이 공통 상태와 구현을 재사용해야 하는 경우에는 추상 클래스를, 서로 관련 없는 클래스들에게 동일한 행위만 강제하거나 한 클래스가 여러 역할을 동시에 수행해야 하는 경우에는 인터페이스를 선택합니다.
