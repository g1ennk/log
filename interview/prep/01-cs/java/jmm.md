# Java Memory Model(JMM)이란 무엇인가요?

## 1. 요약

### 1.1. 결론

Java 메모리 모델 JMM은 멀티스레드 환경에서 메모리 가시성과 명령어 재정렬에 대한 규칙을 정의한 명세입니다.

### 1.2. 왜

컴파일러와 CPU는 성능을 위해 명령어를 재배치하고, 스레드마다 공유 변슈의 최신 값을 즉시 볼 수 없어, JMM은 happens-before 관계로 이런 상황에서도 실행 순서와 가시성을 예측 가능하게 만듭니다.

### 1.3. 원리

같은 스레드 내 실행 순서, volatile 쓰기와 이후 읽기, synchronized 락 해제와 이후 락 획득 사이에는 이 관계가 성립해 앞선 작업의 결과가 뒤에 그대로 보입니다.

### 1.4. 장단점 및 실무

따라서 단순 상태 플래그는 volatile로 충분하지만 복합 연산까지는 보장하지 않아, 여러 변수를 함께 바꿔야 할 때는 synchronized나 Lock을 쓰는 것이 안전합니다.
