# 상속이란 / 언제 사용하는가

## 1. 요약

### 1.1. 결론

상속은 상위 클래스가 가진 필드와 메서드를 하위 클래스가 물려받아 재사용하는 메커니즘입니다.

### 1.2. 왜

여러 클래스가 공통된 속성과 행위를 각자 중복해서 작성하면 유지보수 비용이 커지는 문제가 있고, 상속은 공통 로직을 상위 클래스에서 한 번만 정의하고 하위 클래스가 이를 물려받게 해 이 문제를 해결합니다.

### 1.3. 원리

자바에서는
`extends` 키워드로 상속을 표현하며, 자식이 부모의 한 종류라는 is-a 관계를 만족할 때 사용하는 것이 원칙입니다.

### 1.4. 장단점 및 실무

상속을 사용하면 코드 중복을 줄이고, 자식 클래스가 오버라이딩한 메서드가 실행되는 다형성의 기반을 만들 수 있습니다. 다만 상속은 부모 클래스의 구현 변경이 자식 클래스에 그대로 영향을 끼치며 강한 결합을 만들고, 컴파일 시점에 관계가 고정되어 유연성이 떨어진다는 단점이 있습니다. 또한 is-a 관계가 명확하지 않다면 상속 대신, 다른 객체를 필드로 두고 위임하는 컴포지션을 사용해 결합도를 낮추는 방식도 존재합니다.
