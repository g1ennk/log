# Call By Value와 Call By Reference에 대해서 설명해주세요.

## 1. 요약

### 1.1. 결론

Call By Value는 메서드 호출 시 인자의 값을 복사하여 전달하는 방식이고, Call By Reference는 인자의 참조 자체를 전달하여 호출자와 피호출자가 동일한 변수를 공유하는 방식입니다.

### 1.2. 왜

인자 전달 방식에 따라 원본 데이터의 변경 가능 여부가 갈리는데, Java에서 참조 타입 전달을 "참조에 의한 호출"로 오해할 수 있어 구분이 필요합니다.

### 1.3. 원리

Java의 경우 항상 Call By Value로 동작합니다. 원시 타입은 값 자체가 복사되고, 참조 타입은 힙 영역 객체의 주소값이 복사됩니다. 따라서 메서드 내에서 객체의 내부 상태를 변경하면 원본에 반영되지만, 파라미터에 새 객체를 재할당하면 원본 변수에는 영향이 없습니다.

반대로 C++의 `&`가 대표적인 Call By Reference로 호출자의 변수와 피호출자의 파라미터가 동일한 메모리 주소를 가리키기 때문에, 파라미터 수정 시 변수 재할당을 포함하여 원본에도 그대로 반영됩니다.

### 1.4. 장단점 및 실무

따라서 Java에서 원시 타입처럼 값 자체를 보호해야 하는 경우에는 Java의 Call By Value 특성을 활용하고, 참조 타입의 내부 상태를 방지해야 하는 경우에는 방어적 복사나 String 같은 불변 객체를 선택하는 것이 효율적이라고 생각합니다.
