# 연결 리스트에 대해서 설명해주세요.

## 1. 요약

### 1.1. 결론

연결 리스트는 데이터를 담은 노드들이 포인터로 서로 연결되어 있는 선형 자료구조입니다.

### 1.2. 왜

배열은 크기를 미리 정하고 중간에 데이터를 넣거나 뺄 때 뒤따라는 원소를 모두 옮겨야하는데, 연결리스트는 각 노드를 독립된 메모리 공간에 두고 다음 노드를 가리키는 포인터만 연결해 이 문제를 해결합니다.

### 1.3. 원리

이러한 구조로 연결 리스트는 특정 위치 접근 시 head부터 순차적으로 따라가야 해 O(n)이 걸리지만, 이미 위치를 알고 있는 노드의 앞뒤 데이터를 추가하거나 삭제하는 연산하는 포인터만 변경하면 되므로 O(1)에 처리됩니다. 반면 배열은 인덱스로 O(1)로 접근하지만 중간 삽입 삭제는 O(n)이 걸려, 두 자료구조가 정확히 반대되는 트레이드오프를 가집니다.

### 1.4. 장단점 및 실무

따라서 인덱스 기반의 빠른 조회가 필요한 경우에는 ArrayList를, 앞뒤에서 데이터가 자주 바뀌고 제거되는 큐나 스택 형태의 로직에는 LinkedList를 선택합니다.
