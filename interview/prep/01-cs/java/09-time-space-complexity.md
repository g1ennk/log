# 시간 복잡도와 공간 복잡도의 차이점은 무엇인가요?

## 1. 요약

### 1.1. 결론

시간 복잡도는 입력 크기 n에 대해 `연산 수의 증가 추세`를, 공간 복잡도는 `추가 메모리 사용량의 증가 추세`를 나타냅니다.

### 1.2. 왜

하나의 문제를 푸는 알고리즘은 여러 가지가 존재하는데, 그 중 어떤 알고리즘이 얼마나 효율적인가를 측정할 수 있는 기준이 필요했습니다. 실행 시간이나 메모리는 하드웨어와 언어에 따라 달라질 수 있기에 입력 크기 n에 대해 연산 수와 메모리 사용량이 어떻게 증가하는지를 기준으로 알고리즘의 성능을 평가하게 되었고, 이 척도가 바로 시간/공간 복잡도입니다.

### 1.3. 원리

이 둘을 계산할 때 가장 많이 쓰는 표기법이 빅오 표기법으로, 입력이 충분히 커졌을 때 최악 시간 상한을 나타냅니다. 이때 상수와 저차항을 모두 버리고 계산합니다. 즉, 핵심은 절대 성능이 아니라 "n이 커질 때 얼마나 나빠지는가"이기 때문에 상수나 저차항은 버리고 증가율만 봅니다. 또 둘은 트레이드오프 관계가 잦아 메모이제이션처럼 시간을 아끼려면 공간을 더 쓰고, 공간을 아끼면 시간이 더 드는 식입니다.

### 1.4. 장단점 및 실무

현대 서버 환경에서는 대용량 데이터 처리나 API 응답 지연처럼 스케일에 민감한 상황에선 시간 복잡도를 먼저 보고, MySQL 쿼리 결과를 메모리에 모두 올리는 경우처럼 힙 폭증이나 GC 압력이 우려될 때 공간 복잡도를 함께 고려하기도 합니다.
