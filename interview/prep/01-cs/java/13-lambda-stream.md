# 람다와 스트림이란?

## 1. 요약

### 1.1. 결론

람다는 익명 함수를 간결하게 표현하는 문법이고, 스트림은 이 람다를 활용해 컬렉션 처리를 선언적으로 표현하는 API입니다.

### 1.2. 왜

자바 8 이전에는 정렬 기준이나 필터 조건 같은 동작을 전달하려면 익명 클래스로 인터페이스를 구현해야 해서 코드가 장황했는데, 람다는 함수형 인터페이스의 구현체를
`(매개변수) -> 실행문` 형태로 즉석에서 만들 수 있게 해 이 문제를 해결하였습니다.

### 1.3. 원리

스트림은 람다를 `filter`, `map` 같은 중간 연산과 `collect` 같은 최종 연산에 전달해 데이터 처리 파이프라인을 구성하는 API입니다.
중간 연산은 최종 연산이 호출될 때까지 실행되지 않는 지연 연산 방식으로 동작하며, `findFirst`, `anyMatch` 같은 short-circuit 최종 연산은 조건을 만족하면 순회를 일찍 멈출 수 있습니다.

### 1.4. 장단점 및 실무

단, 스트림 체이닝은 예외 발생 시 디버깅이 까다로워지고, 병렬 스트림은 데이터 양이 적거나 연산이 단순하면 스레드 분배 오버헤드 때문에 오히려 느려질 수 있어, 데이터 양과 연산의 독립성을 확인한 후 병렬 스트림을 선택적으로 적용하기도 합니다.
