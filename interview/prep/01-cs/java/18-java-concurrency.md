# 자바의 동시성 이슈

## 1. 요약

### 1.1. 결론

자바의 동시성 이유는 여러 스레드가 공유 자원에 접근할 때 발생하는 가시성 문제와 원자성 문제로 크게 나눌 수 있습니다.

### 1.2. 왜

가시성 문제는 한 스레드가 변경한 값이 CPU 캐시에만 반영되고, 메인 메모리로 즉시 전파되지 않아, 다른 스레드가 오래된 값을 읽게 되는 문제입니다.

원자성 문제는 count++ 연산처럼 읽기->계산->쓰기 여러 단계로 이뤄진 연산이 중간에 다른 스레드의 개입으로 끼어들어 일부 연산 결과가 소실되는 문제입니다.

### 1.3. 원리

이 두 문제가 겹쳐서 실행 순서에 따라 결과가 달라지는 상황을 `경쟁 상황(race condition)`이라고 부르며, 자바는 가시성 문제에는 `volatile`, 원자성 문제에는 `synchronized`나
`AtomicInteger` 같은 원자적 클래스를 제공해 해결합니다.

### 1.4. 장단점 및 실무

실무에서는 공유 상태를 최대한 줄이고 불변 객체를 활용하는 방식으로 애초에 동시성 문제가 발생할 여지를 줄이는 것을 우선하고, 공유 상태가 불가피한 경우에만 `volatile`이나
`synchronized`, 원자적 클래스를 상황에 맞게 선택해야 합니다.
