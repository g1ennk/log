# 네트워크에서 회선 교환 방식과 패킷 교환 방식은 어떤 차이점 있나요?

## 1. 요약

### 1.1. 결론

- 회선 교환과 패킷 교환은 네트워크 자원을 통신 내내 독점 예약하느냐, 필요할 때만 나눠 쓰느냐에서 갈리는 두 가지 통신 방식이다.

### 1.2. 왜

- 여러 사용자가 하나의 통신망을 공유해야 하는데, 회선을 통화 내내 독점 예약할지 필요한 순간에만 패킷 단위로 나눠 쓸지에 대한 선택이 필요해서 두 방식이 갈렸다.

### 1.3. 원리

- 회선 교환: 통신 시작 전 출발지-목적지 간 전용 경로(회선)를 미리 설정하고, 통신이 끝날 때까지 독점한다.
- 패킷 교환: 데이터를 패킷 단위로 쪼개 각각 독립적으로 최적 경로를 찾아 전송하고(라우터가 전달), 목적지에서 재조립한다.
- 대비축: 회선 교환은 자원을 미리 예약해 지연이 안정적인 대신 유휴 시간에도 점유해 비효율적이고, 패킷 교환은 전송할 때만 자원을 써서 공유 효율은 높지만 경로 탐색·헤더 오버헤드로 지연이 변동적이다.

### 1.4. 판단 기준

- 지연 안정성이 중요한 실시간 음성·영상 통화는 회선 교환이 적합했다.
- HTTP, 이메일, 파일 전송처럼 데이터 통신 위주인 오늘날 인터넷(TCP/IP)은 패킷 교환을 쓴다.
