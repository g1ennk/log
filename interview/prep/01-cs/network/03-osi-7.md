# OSI 7 계층 모델을 설명해주세요

## 1. 요약

### 1.1. 결론

- OSI 7계층은 네트워크 통신을 7단계로 나눠 각 계층이 독립적인 역할만 맡게 한 참조 모델이다.

### 1.2. 왜

- 계층을 나누지 않으면 통신 기능 전체가 하나로 뒤엉켜, 하위 계층(예: 물리 매체) 하나만 바뀌어도 상위 계층 전부를 다시 설계해야 한다. 계층별로 책임을 분리해 한 계층의 변화가 다른 계층에 영향을 주지 않게 하려고 만들어졌다.

### 1.3. 원리

- 각 계층은 하위 계층의 서비스를 받아 상위 계층에 새로운 서비스를 제공한다. 1·2(물리·데이터링크)는 비트·프레임 전송, 3(네트워크)은 IP 기반 경로 선택, 4(전송)는 TCP/UDP로 프로세스 간 통신, 5~7(세션·표현·응용)은 연결 관리부터 애플리케이션 프로토콜까지 담당한다.
- 실무에선 이 7계층을 그대로 쓰지 않고 5~7을 응용, 1~2를 네트워크 접근으로 합쳐 **TCP/IP 4계층**(응용-HTTP/FTP/DNS, 전송-TCP/UDP, 인터넷-IP, 네트워크 접근-Ethernet)으로 쓴다.

### 1.4. 판단 기준

- 장애 발생 시 "어느 계층 문제인지" 원인을 좁히는 틀로 쓰고, L4 로드밸런서 vs L7 로드밸런서 선택 근거가 된다 — Nginx도 4계층·7계층 양쪽으로 동작 가능하다.
- 다만 OSI 7계층 자체는 이론적 참조 모델이라 실제 구현엔 쓰지 않는다는 점은 짚어야 한다.
