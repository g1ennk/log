# @Value 어노테이션 사용 시 주의할 점을 설명해주세요.

## 1. 요약

### 1.1. 결론

가장 큰 주의점은 static·final 필드에는 값이 주입되지 않고, 프로퍼티가 없거나 타입이 안 맞으면 애플리케이션 기동 자체가 실패한다는 것입니다.

### 1.2. 왜

@Value의 값 주입은 Bean이 생성된 뒤 런타임에 처리되는데, static 필드는 클래스 로딩 시점에 이미 값이 고정돼야 해서 타이밍이 어긋나기 때문입니다.

### 1.3. 원리

그래서 인스턴스 필드에는 정상 주입되지만 static·final 필드에는 적용되지 않습니다. 또 콜론으로 기본값을 지정하지 않은 채 프로퍼티가 없거나 타입이 안 맞으면, 컴파일 타임이 아니라 기동 시점에야 예외로 드러납니다.

### 1.4. 장단점 및 실무

값이 늘어나면 필드가 흩어져 응집도가 떨어지고 테스트에서 값을 목킹하기도 번거로우므로, 값이 한두 개면 @Value를 쓰고 여러 개면 별도 설정 클래스로 묶어 타입 세이프하게 바인딩합니다.
