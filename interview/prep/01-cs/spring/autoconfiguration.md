# AutoConfiguration 동작 원리를 설명해주세요.

## 1. 요약

### 1.1. 결론

AutoConfiguration은 classpath에 어떤 라이브러리가 있는지 보고 필요한 Bean들을 Spring Boot가 자동으로 등록해주는 메커니즘입니다.

### 1.2. 왜

라이브러리를 쓸 때마다 개발자가 일일이 Bean을 등록하는 번거로움을 없애고, 정해진 관례대로 빠르게 애플리케이션을 구동하기 위해 도입되었습니다.

### 1.3. 원리

@SpringBootApplication에 포함된 @EnableAutoConfiguration이 자동 구성 후보 목록을 읽어오고, 조건부 어노테이션으로 실제 등록 여부를 걸러냅니다. 만약 사용자가 같은 타입의 Bean을 직접 등록했다면 자동 구성은 조건에 걸려 뒤로 물러납니다.

### 1.4. 장단점 및 실무

이러한 방식은 편리하지만 어떤 Bean이 왜 자동으로 등록되었는지 추적하기 어려워 원인 파악이 힘들다는 단점이 있습니다. 이럴 때는 실행 시 자동 구성 적용·제외 내역을 보여주는 리포트로 원인을 추적합니다.
