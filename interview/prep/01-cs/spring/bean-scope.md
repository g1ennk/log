# Spring의 Bean Scope 종류를 설명해주세요

## 1. 요약

### 1.1. 결론

Bean Scope는 컨테이너가 Bean 인스턴스를 몇 개 만들고 어떤 범위 동안 유지할지를 결정하는 설정입니다.

### 1.2. 왜

대부분의 Bean은 상태가 없어 재사용해도 되지만, 매번 새 인스턴스가 필요하거나 요청, 세션 단위로 데이터를 유지해야 하는 상황도 있어 다양한 스코프가 생겼습니다.

### 1.3. 원리

기본 스코프 싱글톤은 컨테이너 종료까지 하나의 인스턴스를 유지하고,
프로토타입은 조회 시마다 새 인스턴스를 만든 뒤 컨테이너가 관리하지 않습니다.
웹 환경에서는 request, session 스코프로 요청 및 세션 단위 격리도 가능합니다.

### 1.4. 장단점 및 실무

싱글톤은 재사용으로 성능은 좋지만 상태를 가지면 동시성 문제가 생기고,
프로토타입은 상태 격리는 되지만 생성 비용이 생기고 소멸 콜백도 보장되지 않습니다.
따라서 싱글톤 Bean이 프로토타입 Bean을 주입받다 재사용되는 문제가 발생하면 지연 조회로 새 인스턴스를 가져오도록 설계하기도 합니다.
