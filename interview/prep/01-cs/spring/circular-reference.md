# 스프링에서 순환 참조가 발생하는 이유와 해결법은?

## 1. 요약

### 1.1. 결론

순환 참조는 두 개 이상의 Bean이 서로를 의존하고 있어 컨테이너가 어떤 Bean을 먼저 생성해야 할지 결정할 수 없는 상황입니다.

### 1.2. 왜

Bean A가 B를 Bean B가 A를 필요로 하면 하나를 완성하기 위해선 다른 하나가 먼저 완성돼 있어야 하는 모순이 생겨 순환 참조가 발생합니다.

### 1.3. 원리

생성자 주입은 생성 시점에 의존관계가 모두 확정돼야 하므로 구동 즉시 순환 참조가 드러나지만,
필드나 생성자 주입은 주입 시점이 분리돼 순환되는 메서드를 호출할 때 비로소 문제가 드러납니다.

### 1.4. 장단점 및 실무

해결법으론 지연 주입이나 필드, 생성자 주입으로 순환 고리를 끊으면 일단 구동은 되지만, 두 Bean이 서로 강하게 의존한다는 문제 자체는 남아있어 더 큰 복잡도로 나중에 돌아올 수 있습니다.
따라서 우회 방법보다는 공통 로직을 별도 Bean으로 분리하거나 상위 계층에서 조합하는 방향으로 재구조화하는 방법도 쓰입니다.
