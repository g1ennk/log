# Spring Bean의 생명주기를 설명해주세요

## 1. 요약

### 1.1. 결론

Spring Bean의 생명주기는 컨테이너가 Bean을 생성해 의존관계를 주입하고, 초기화 콜백을 거쳐 사용하다가 종료 시 소멸 콜백을 호줄하는 과정입니다.

### 1.2. 왜

객체 생성 시점에서는 아직 의존관계가 채워지지 않아 DB 연결 같은 무거운 초기화 작업을 안전하게 수행할 수 없고, 종료 시에도 연결 해제 같은 정리 시점을 프레임워크가 알랴줘야 할 필요가 있었습니다.

### 1.3. 원리

Bean은 생성자 호출 후 의존관계 주입이 끝나면 초기화 콜백이, 컨테이너 종료 직전에는 소멸 콜백이 호출됩니다. 이 콜백은 인터페이스 구현, 설정 정보 지정, 자바 표준 애노테이션 세 가지 방식으로 지정할 수 있습니다.

### 1.4. 장단점 및 실무

인터페이스 방식은 스프링에 코드가 종속되고 메서드 이름도 고정되기 때문에 대부분 표준 애노테이션 방식을 쓰되 소스를 수정할 수 없는 외부 라이브러리 Bean에만 설정 정보 메서드를 지정하기도 합니다.

1. 자바 표준 애노테이션
    - @PostConstruct
    - @PreDestroy
2. 설정 정보 지정 방식
    - 라이브러리 클래스(애노테이션 부착 불가)
    - Spring 설정 클래스
        - @Bean(initMethod="init", destroyMethod="destroy")
        - AppConfig(@Configuration)
3. 인터페이스 구현 방식
    - InitializingBean
    - DisposableBean
