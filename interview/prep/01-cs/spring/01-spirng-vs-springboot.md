# Spring과 Spring Boot의 차이를 말해주세요.

## 1. 요약

### 1.1. 결론

Spring과 Spring Boot 모두 IoC와 DI로 객체 생성과 의존관계 관리를 프레임워크에 위임한다는 공통 목적은 같습니다.

### 1.2. 왜

단, Spring Framework는 개발자가 XML이나 자바 설정으로 Bean과 인프라를 직접 구성해야 하는 반면, Spring Boot는 그 위에서 자동 설정과 내장 웹 서버, 스타터 의존성을 제공해 개발자의 설정 부담을 줄여줍니다.

### 1.3. 원리

Spring은 구성 요소를 세밀하게 제어하지만 초기 설정 비용이 크고, Spring Boot는 생산성이 높지만 자동 등록되는 Bean이 너무 많아 내부 동작 파악이 어려울 때가 있습니다.

### 1.4. 장단점 및 실무

따라서 신규 프로젝트는 기본적으로 Spring Boot로 시작하되 자동 설정 탓에 원인이 불분명한 문제가 생기면 등록되 Bean과 조건부 설정을 직접 확인하며 추적하는 방식으로 대응하는 것이 좋습니다.
