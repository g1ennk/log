# AOP의 동작 원리와 프록시 기반 구현을 설명해주세요.

## 1. 요약

### 1.1. 결론

AOP는 로깅이나 트랜잭션처럼 여러 로직에 공통으로 필요한 횡단 관심사를 핵심 로직에서 분리해 관리하는 방식입니다.

### 1.2. 왜

공통 기능을 메서드마다 작성하면 코드가 중복되고 가독성이 떨어지기 때문에 부가 기능을 한곳에 모듈화해 필요한 지점에 자동 적용할 방법이 필요했습니다.

### 1.3. 원리

Spring AOP는 이를 프록시 패턴으로 구현합니다. 클라이언트는 실제 객체 대신 프록시를 주입받고, 프록시가 부가 기능을 먼저 실행한 뒤 실제 객체에 위임합니다.

### 1.4. 장단점 및 실무

기억해야 할 건 프록시를 거치지 않는 호출에는 AOP가 적용되지 않는다는 점입니다. 같은 클래스 내부 호출이 대표적으로 트랜잭션이 필요한 메서드를 별도 빈으로 분리해 항상 프록시를 거치도록 설계해야 합니다.
