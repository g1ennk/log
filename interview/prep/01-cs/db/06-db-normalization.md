# 데이터베이스 정규화에 대해서 설명해주세요.

## 1. 요약

### 1.1. 결론

정규화는 하나의 테이블에 몰려 있는 데이터를 함수 종속 관계에 따라 여러 테이블로 분해해, 데이터 중복을 줄이고 삽입/갱신/삭제 이상을 막는 과정입니다.

### 1.2. 왜

한 테이블에 정보를 몰아넣으면 같은 값이 여러 행에 중복 저장되고, 그 값을 고칠 때 일부 행만 수정되면 데이터끼리 서로 모순되는 이상 현상이 생기기 때문에 정규화가 필요합니다.

### 1.3. 원리

1NF는 칼럼 값을 더 쪼갤 수 없는 원자 값으로 만드는 단계, 2NF는 기본 키 일부에만 종속된 부분 함수 종속을 제거하는 단계, 3NF는 키가 아닌 속성 끼리 이어지는 이행적 종속을 제거하는 단계, BCNF는 여기서 더 나아가 모든 결정자가 후보 키가 되도록 엄격하게 분해하는 단계입니다.

### 1.4. 장단점 및 실무

정규화를 하면 무결성은 좋아지지만 조회 시마다 여러 테이블을 JOIN해야 해서 읽기 성능이 떨어지는 트레이드오프가 있습니다. 따라서 주문이나 결제처럼 무결성이 중요한 테이블은 정규화를 유지하고, 좋아요 수처럼 읽기가 잦은 집계성 데이터는 컬럼에 값을 미리 저장해두는 역정규화를 선택적으로 적용합니다.
